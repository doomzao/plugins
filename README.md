# doomzao's Dalamud plugins

One URL gives you access to all my FFXIV plugins, current and future. Add it once and every new plugin I release shows up in your installer automatically.

## How to add

1. In game, type `/xlsettings` and open the **Experimental** tab.
2. Under **Custom Plugin Repositories**, paste the URL below into an empty box:

   ```
   https://raw.githubusercontent.com/doomzao/plugins/main/repo.json
   ```

3. Click the **+** button on the right, then the **save** button at the bottom right.
4. Open `/xlplugins`: my plugins are now available under **All Plugins**.
